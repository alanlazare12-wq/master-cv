# Sistema de plantillas v29

La biblioteca incluida mantiene 528 presets base: 44 familias × 12 paletas, incluyendo 48 presets de la categoría Con foto.

v29 mantiene la biblioteca base sin inflar artificialmente el número de presets y conserva **Template Forge** como sistema de recetas personales. Cualquier preset base puede convertirse en una receta personal mediante tokens de diseño. Esto produce una biblioteca personal mucho más flexible que multiplicar combinaciones predefinidas.

Las recetas personalizadas se guardan sólo en el navegador y no contienen hechos del CV.
