# Local Creator Pro

## Writing Coach

Analiza bullets de experiencia con reglas locales: verbo de acción, presencia de cifras cuando existen, longitud y contexto. Nunca añade números ni credenciales. Su salida es diagnóstico + estructura de redacción con placeholders.

## Export Integrity

Crea copias temporales de las variantes ATS y presentación, cambia sólo el diseño y compara un fingerprint de hechos junto con la Vista ATS. El CV original no se muta.

## Page Quality

Usa el plan de Layout Composer para detectar páginas con presión alta y balance aproximado. Es una heurística de composición, no un motor tipográfico exacto.

## Template Library

528 presets = 44 familias × 12 paletas. La UI renderiza 60 resultados por página para evitar cargar 528 tarjetas simultáneamente. Favoritos y recientes se guardan localmente.

## Focus Mode

Oculta la navegación lateral para priorizar editor + preview. No cambia datos ni ajustes del CV.
