# Template Forge

Template Forge convierte la configuración visual del CV actual en una **receta local reutilizable**.

Una receta conserva:

- preset base;
- color/acento;
- tipografía;
- una o dos columnas;
- densidad;
- márgenes;
- escala;
- interlineado;
- tamaño de papel;
- estilo de cabecera;
- estilo de títulos;
- divisores;
- presentación de contacto.

No contiene experiencia, nombre, correo, skills ni ningún otro hecho del CV.

Al aplicar una receta se verifica que el fingerprint factual no cambie. La biblioteca local acepta hasta 120 recetas para evitar crecimiento descontrolado de `localStorage`.
